
# AvinashOnline - Starter React E-commerce (Vite + Tailwind)

This is a starter project for **AvinashOnline.com** (sarees & women's wear).

## What's included
- Vite + React app
- Tailwind CSS setup (config included)
- Sample product data and cart
- Placeholder images (use your own for production)

## Quick local setup
1. Install Node.js (v18+ recommended).
2. In project folder:
   ```bash
   npm install
   npm run dev
   ```
3. Open http://localhost:5173

## Deploy to Vercel (recommended)
1. Create a GitHub repo and push this project.
2. Sign in to https://vercel.com with your GitHub account.
3. Import the GitHub repository, Vercel will detect the Vite app and set defaults.
4. Deploy. After successful deploy, go to the Vercel dashboard -> Domains -> Add `AvinashOnline.com`.
5. Purchase the domain from Namecheap/Google Domains/GoDaddy if not already owned, then follow Vercel's DNS instructions.

## Notes about domain & payments
- I cannot register/purchase the domain or deploy to your Vercel account for you.
- To accept payments in India, integrate Razorpay or Stripe India (requires serverless function for secure keys).
- Replace placeholder images in `/public` or use an image CDN.
